# 🌿 Garden Planner (Планировщик сада)

Мощный, модульный и полностью клиентский веб-инструмент для проектирования садовых участков, клумб и ландшафтного дизайна. Поддерживает как детализированный **2D-режим** (SVG), так и интерактивный **3D-режим** (Three.js) со сглаженным рельефом, с возможностью управления задачами, календарём цветения и умным выравниванием объектов.

---

## 🚀 Ключевые возможности

- **Двойной режим отображения**: мгновенное переключение между 2D (векторная графика) и 3D (WebGL) без потери данных.
- **Умное перемещение и Snap**: объекты «примагничиваются» к краям и центрам других объектов. Встроенная проверка коллизий предотвращает наложение клумб друг на друга.
- **3D-ландшафт с рельефом**: участок делится на настраиваемую сетку блоков (2×2 … 5×5), высота каждого блока задаётся отдельно. Рельеф сглаживается билинейной интерполяцией, образуя плавные холмы.
- **Множественное выделение в 3D**: одиночный клик, Ctrl+клик и выделение рамкой (marquee select) для одновременной настройки нескольких блоков.
- **Библиотека объектов**: деревья, кустарники, цветы, дорожки, мульча (с процедурными текстурами) и водоёмы.
- **Календарь цветения**: фильтрация растений по месяцам или точным датам с визуальной подсветкой на холсте.
- **Система задач**: назначение задач (полив, обрезка) конкретным растениям или объектам с приоритетами, дедлайнами и визуальными маркерами.
- **Карта задач**: специальный режим, приглушающий все объекты, кроме тех, у которых есть активные задачи.
- **История действий**: полноценная поддержка Undo/Redo (`Ctrl+Z` / `Ctrl+Y`) с ограничением глубины истории для экономии памяти.
- **Сохранение и экспорт**: автосохранение в `localStorage`, экспорт/импорт проекта в JSON и экспорт плана в PNG.

---

## 🛠 Технологический стек

- **HTML5 / CSS3**: семантическая вёрстка, CSS-переменные, адаптивный Flexbox/Grid layout.
- **Vanilla JavaScript (ES6+)**: модульная архитектура без использования фреймворков (React/Vue) или сборщиков (Webpack/Vite).
- **Three.js (r128)**: для рендеринга 3D-сцены, освещения, OrbitControls и интерактивного рельефа.
- **SVG**: для высококачественного и масштабируемого 2D-рендеринга.

## 🏗 Архитектура и поток данных

Приложение следует однонаправленному потоку данных, похожему на Flux/Redux, но реализованному на чистом JS:

1. **Состояние (`state.js`)**: объект `state` хранит всё — массив объектов (`objects`), выбранный инструмент, историю изменений, настройки 3D-рельефа (`terrainBlocks`, `selectedBlocks`) и режим отображения (`viewMode`).
2. **Действие (`interaction.js`)**: пользователь перетаскивает объект. Скрипт вычисляет новые координаты, проверяет коллизии и snap-условия, затем обновляет `state.objects`.
3. **Реакция (`render/` или `3d/`)**: вызывается функция `render()` (для 2D) или `rebuildThreeScene()` (для 3D), которая полностью перерисовывает холст на основе актуального `state`.
4. **Сохранение (`tasks.js` / `storage.js`)**: при значимых изменениях вызывается `saveState()`, который делает снимок `state.objects` и помещает его в массив истории для Undo.

## 📋 Подробный функционал

### 🎨 1. Холст и навигация
- **Масштабирование (Zoom)** колёсиком мыши с фокусом на курсор.
- **Двойной клик** по пустому месту сбрасывает масштаб и позицию к исходным.
- **Размерная сетка**: настраиваемая сетка с отображением размеров в метрах. Можно менять размер ячейки, цвет и прозрачность.

### 🛠 2. Создание и редактирование объектов
- **Участок (Plot)**: базовый прямоугольник, ограничивающий рабочую область. Его размеры (в метрах) можно задать вручную через правую панель, после чего участок автоматически масштабируется под размер окна (`fitPlotToCanvas`).
- **Клумбы (Beds)**:
  - Три режима создания: прямоугольная, круглая и произвольная фигура (полигон).
  - **Морфинг контура**: у любой клумбы можно перетаскивать узловые точки. Двойной клик по грани добавляет новую точку.
  - **Управление сложностью**: кнопки для увеличения (×2, ×3...) или уменьшения (÷2, ÷3...) количества точек сглаживания контура (с лимитом в 100 точек для производительности).
- **Дорожки (Paths)**: создаются по точкам (полилиния). Имеют настраиваемую ширину и процедурные текстуры.
- **Деревья и Декор**: предустановленные виды (дуб, сосна, берёза, ель, пальма, сакура и др.) и декоративные элементы (водоёмы с анимацией волн).
- **Мульча (Mulch)**: накладывается поверх клумб. Имеет 11 видов текстур (кора, листья дуба, хвоя, гравий, солома, шишки и т.д.) и настраиваемую плотность частиц.

### 🧲 3. Продвинутая система взаимодействия
- **Умное перетаскивание (Drag & Drop)**: объекты можно свободно перемещать. При перемещении клумбы, мульча и растения внутри неё двигаются синхронно.
- **Snap-направляющие (как в Photoshop)**: при приближении клумбы к другой клумбе или участку (в пределах 10 пикселей) появляются красные пунктирные линии, указывающие на выравнивание по краям или центрам. Клумба «примагничивается» к ним.
- **Защита от наложения (Collision Detection)**: алгоритм проверяет пересечение полигонов (`polygonsIntersect`). Если при перемещении или изменении размера клумба пересекает другую, действие блокируется.
- **Манипуляторы (Handles)**:
  - При выделении объекта появляются 8 точек для изменения размера (Resize).
  - Для изменения формы используются специальные точки морфинга.

### 🌿 4. Каталог растений и деревьев
- **Предустановленная база**: 9 видов цветов/трав и 8 видов деревьев с заданными параметрами (цвет, форма, время цветения, высота).
- **Создание своих видов**: пользователь может создать кастомное растение или дерево, задав имя, цвет, форму иконки, высоту, размер и количество цветов.
- **Папки (Folders)**: возможность группировать растения и деревья в папки для удобства навигации (создание, переименование, удаление через контекстное меню по правому клику).
- **Детальные свойства посадки**: при клике на конкретное растение на клумбе открывается popup, где можно изменить:
  - Вид растения.
  - Форму отображения (круг, звезда, лист, капля и т.д.).
  - Размер иконки.
  - **Индивидуальный график цветения**: можно задать месяцы или точные даты (день и месяц) начала и конца цветения для конкретной посадки.

### 📋 5. Система задач и напоминаний
- Каждому объекту (дереву) или конкретной посадке можно назначить задачи (например, «Обработать от тли», «Полить»).
- **Параметры задачи**: описание, дедлайн (дата), приоритет (Низкий 🟢, Средний 🟡, Высокий 🟠, Срочный 🔴).
- **Визуализация на холсте**: над объектами с активными задачами появляются цветные маркеры с количеством невыполненных дел. Просроченные задачи подсвечиваются красным.
- **Типы подсветки**: маркер, свечение (glow), пульсация (pulse), рамка (border).
- **Панель задач**: отдельная боковая панель со списком всех задач, поддержкой фильтрации (по статусу: активные/выполненные/просроченные, и по приоритету).
- **Режим «Карта задач»**: специальная кнопка, которая приглушает все объекты на холсте, кроме тех, у которых есть активные задачи, фокусируя внимание на требующих ухода зонах.

### 🏔️ 6. 3D-режим визуализации
- **Блочный рельеф (Terrain)**: участок делится на сетку (2×2, 3×3, 4×4, 5×5).
- **Сглаживание**: высота в любой точке вычисляется через **билинейную интерполяцию** между 4 окружающими блоками — получаются плавные холмы, а не ступеньки.
- **Редактирование высоты**: клик по блоку открывает панель, где можно изменить его высоту (0–5 м).
- **Множественное выделение**:
  - ЛКМ — одиночный выбор блока.
  - Ctrl+ЛКМ — добавить/убрать блок из выделения.
  - ЛКМ + тянуть — выделение рамкой (marquee select).
- **Синхронная настройка**: ползунок высоты изменяет сразу все выбранные блоки.
- **Кнопка «Сброс»** и **«Снять выделение»** для массовых операций.
- **3D-объекты**: деревья, кусты, дорожки, мульча и водоёмы автоматически пересчитывают свои координаты Y через `getTerrainHeightAt2D()`, чтобы «сидеть» на поверхности рельефа, а не парить в воздухе или проваливаться под землю.
- **Управление камерой**: ПКМ — вращение, колёсико — зум, ЛКМ — выделение.

### 💾 7. Сохранение, Экспорт и Импорт
- **Автосохранение в браузере**: все изменения сохраняются в `localStorage`. При следующем открытии приложение предложит загрузить последний сеанс.
- **Экспорт в JSON**: полное резервное копирование проекта в файл `.json` (включая кастомные растения, папки, задачи и настройки 3D-рельефа).
- **Импорт из JSON**: загрузка ранее сохранённого проекта. Встроен механизм миграции (`migrateOldProject`), который автоматически обновляет структуру старых файлов до актуальной версии.
- **Экспорт в PNG**: генерация растрового снимка текущего вида холста (с учётом всех слоёв) для скачивания.

### 🎨 8. Процедурная генерация текстур
Вместо использования тяжёлых растровых изображений, приложение генерирует текстуры «на лету» с помощью SVG:
- **Мульча и дорожки**: алгоритм разбивает область на сегменты и заполняет их сотнями мелких SVG-элементов (камешков, иголок, листьев), положение, размер, поворот и оттенок которых рандомизируются с помощью **детерминированного генератора псевдослучайных чисел** (`particleRand`). Это гарантирует, что текстура выглядит органично, но при этом одинаково при каждом рендере (без «мигания» при обновлении).

## ⚙️ Ключевые алгоритмы

### 1. Snap-выравнивание и запрет коллизий (`geometry.js`)
При перемещении клумбы алгоритм:
1. Вычисляет `BoundingBox` перемещаемого и целевых объектов.
2. Функция `computeSnapGuides` ищет совпадения краёв или центров с допуском `SNAP_THRESHOLD` (10px).
3. Функция `polygonsIntersect` проверяет пересечение полигонов (через проверку вхождения точек и пересечения отрезков).
4. Если пересечение есть — перемещение блокируется. Если нет — применяются координаты snap-выравнивания.

### 2. Билинейная интерполяция рельефа (`three-terrain.js`)
Функция `getSmoothHeightAt(vx, vz)` вычисляет высоту в любой точке ландшафта:
1. Находит 4 окружающих блока по координатам.
2. Вычисляет дробные части `fx`, `fz` внутри ячейки.
3. Интерполирует по X на верхнем и нижнем рядах, затем по Z между ними.
4. Результат — плавный переход между блоками разной высоты.

### 3. Marquee select (`three-view.js`)
При выделении рамкой в 3D:
1. Центры всех блоков проецируются на экран через `Vector3.project(camera)`.
2. Проверяется попадание экранных координат в DOM-рамку.
3. Дополнительно проверяется `screenPos.z < 1`, чтобы не выделять блоки за камерой.

### 4. Система Undo/Redo (`tasks.js`)
- `saveState()`: сериализует `state.objects` через `JSON.parse(JSON.stringify(...))`. Если новое состояние идентично последнему в истории, оно игнорируется.
- Массив `state.history` ограничен константой `MAX_HISTORY` (50 шагов) для предотвращения утечек памяти.
- `undo()` и `redo()` просто перемещают указатель `state.historyIndex` и заменяют текущие объекты на сохранённый снимок, после чего вызывают `render()`.

## 🚀 Как запустить проект

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/Andrew-V-o/Garden.git
   cd Garden
   ```

2. **Запуск**:
